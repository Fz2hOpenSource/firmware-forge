# map-parser — Keil .map File Analysis
> 路径约定：本文件中的 `python tools/...` 为相对技能根目录的写法，运行前请先按 SKILL.md 的 **Tool Path Resolution** 解析为绝对路径。


Companion CLI shipped in `tools/map-parser/`. Resolve its absolute path via
the skill's `Tool Path Resolution` rules. Parses armlink-generated `.map`
files only; read-only by design.

Use `tools/map-parser/map-parser.py` to query symbol addresses, memory regions, and section layout from Keil MDK-ARM `.map` files. This is useful when debugging, verifying memory placement, or checking the address of a global variable. Resolve the script path as described in `Tool Path Resolution` above.

### Commands

```bash
# Map file overview (symbol count, flash/RAM usage)
python tools/map-parser/map-parser.py info <map_file>

# Find symbols by name (supports *, ? and comma-separated patterns)
python tools/map-parser/map-parser.py find <map_file> <pattern> [--data] [--compact]

# Show memory section details
python tools/map-parser/map-parser.py section <map_file> <section_name>

# List symbols near an address
python tools/map-parser/map-parser.py range <map_file> <address>

# List all load/execution regions
python tools/map-parser/map-parser.py sections <map_file> [--summary]

# HardFault address analysis (PC required, others optional)
python tools/map-parser/map-parser.py fault <map_file> --pc <addr> [--lr <addr>] [--addr <addr>] [--sp <addr>]

# Rank memory usage by object file or section
python tools/map-parser/map-parser.py size-rank <map_file> --by object|section [--top N]

# Check MPU region alignment and symbol placement
python tools/map-parser/map-parser.py mpu-check <map_file> --region <name> --base <addr> --size <bytes>
```

### Examples

```bash
# Quick overview
python tools/map-parser/map-parser.py info firmware.map

# Find a specific variable
python tools/map-parser/map-parser.py find firmware.map "s_dma_channels"

# Find multiple variables at once (comma-separated)
python tools/map-parser/map-parser.py find firmware.map "s_dma_channels,s_raw_rings,s_sample_aligner"

# Find all variables starting with s_ (Data symbols only)
python tools/map-parser/map-parser.py find firmware.map "s_*" --data

# Compact output (auto-enabled when >50 results)
python tools/map-parser/map-parser.py find firmware.map "s_*" --data --compact

# Check what symbols are at or near a given address
python tools/map-parser/map-parser.py range firmware.map "0x20004ddc"

# Compact section list (avoids truncated output for large map files)
python tools/map-parser/map-parser.py sections firmware.map --summary

# HardFault analysis: PC + LR + access address
python tools/map-parser/map-parser.py fault firmware.map --pc 0x0800b455 --lr 0x0800c55d --addr 0x20000008

# Top 10 largest object files (Flash usage)
python tools/map-parser/map-parser.py size-rank firmware.map --by object --top 10

# Check MPU alignment for RW_IRAM2 region
python tools/map-parser/map-parser.py mpu-check firmware.map --region RW_IRAM2 --base 0x24008000 --size 57344
```

### Output Format

All commands return JSON. Standard output:

```json
{
  "status": "ok",
  "count": 3,
  "symbols": [
    {
      "name": "s_dma_channels",
      "address": "0x20004ddc",
      "address_int": 536890844,
      "type": "Data",
      "size": 276,
      "object_section": "instrument_sensor_dma.o(.bss)"
    }
  ]
}
```

Compact output (with `--compact` flag):

```json
{
  "status": "ok",
  "count": 3,
  "compact": true,
  "symbols": [
    {"n": "s_dma_channels", "a": "0x20004ddc", "s": 276, "o": "instrument_sensor_dma.o(.bss)"}
  ]
}
```

The `range` command also includes the `memory_region` field identifying which execution region contains the address.

### Notes

- Only Keil ARMCC5/ARMClang `.map` format is currently supported (the format generated by `armlink`).
- Symbols are searched from both Local and Global sections.
- Each symbol includes `type_norm` (standardized: CODE/DATA/SECTION/NUMBER/UNDEF) alongside the raw `type` field for cross-version compatibility.
- The `fault` command's `--pc` is required; `--lr`, `--addr`, and `--sp` are optional context enrichments.
- The `mpu-check` command validates ARM MPU alignment requirements (base must align to power-of-2 size).
- The tool does not read firmware or modify any files; it only queries the map file.
