# M3

## Key Constraints

- No cache.
- Standard Cortex-M priority model and fault handling.
- Use explicit critical sections around shared state.

## Recommended Patterns

- Use interrupt-driven pipelines for peripherals that need responsiveness.
- Keep DMA and ISR ownership clear.
- Use fixed-size buffers and avoid unnecessary heap allocation.

## Common Risks

- Priority inversion from long critical sections.
- Unclear ownership between ISR and task code.
- HardFaults caused by invalid pointers or stack pressure.
